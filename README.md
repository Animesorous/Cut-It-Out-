# ✂️ Cut It Out!

A free, privacy-friendly image border remover that runs directly in your browser.

Cut It Out! automatically removes unwanted white backgrounds and borders from images in batches, without uploading your images to a server.

## ✨ Features

- 🖼️ Batch processing
- ✂️ Two cropping modes:
  - **Safe / Normal** — conservative border removal
  - **Aggressive / All White** — removes white background more aggressively
- 🎚️ Adjustable tolerance
- 🛡️ Adjustable safety margin
- 👀 Live preview
- 📦 Download all processed images as a ZIP
- 🔒 Images are processed locally in your browser
- 🆓 Completely free
- 📱 Works on phones, tablets, and computers

## 🔐 Privacy

Your images are processed directly on your device.

They are not uploaded to a server or stored by Cut It Out!

## 🚀 How to Use

1. Select or drag your images into Cut It Out!
2. Choose **Safe / Normal** or **Aggressive / All White**.
3. Adjust the tolerance and safety margin if needed.
4. Click **Clean Images**.
5. Download individual images or download everything as a ZIP.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- HTML Canvas API

No backend or database is required.
